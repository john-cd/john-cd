# John Cruchon-Dupeyrat

I work across data engineering, search, machine learning, and software architecture. My public
projects include Rust tools, documentation, and developer infrastructure.

## Public repositories

- [Personal site](https://github.com/john-cd/john-cd.github.io) — writing and project notes on data
  engineering, search, machine learning, and software architecture.
- [Cheatsheets](https://github.com/john-cd/cheatsheets) — practical programming references and
  guides, published as a searchable documentation site.
- [Rust How-to](https://github.com/john-cd/rust_howto) — a compendium of recipes for Rust and its
  ecosystem.
- [mdbook-utils](https://github.com/john-cd/mdbook-utils) — command-line tools for maintaining
  links, reference definitions, and code examples in Markdown books.
- [Rust GitHub Action](https://github.com/john-cd/rust_github_action) — a Docker action that builds
  Rust code and exports the resulting application image.
- [test_github_action](https://github.com/john-cd/test_github_action) — a hosted workflow that
  exercises the Rust container action and checks its exported image.
- [rust_template](https://github.com/john-cd/rust_template) — a cross-platform Rust workspace
  starter with a library, CLI, CI, devcontainer, and project site.
- [Profile README source](https://github.com/john-cd/john-cd) — this profile repository.
